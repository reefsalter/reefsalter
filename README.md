# Hey, I'm Reef

Student pilot from the UK, working towards an ATPL(A). Commercial licence done, multi-engine and instrument rating next, based in Bournemouth.

I also build things. Most of it exists because flight training creates a ridiculous amount of admin, and I'd rather automate it once than do it twice.

## Flying

[![Logbook summary](https://reefsalter.com/badges/logbook.png)](https://reefsalter.com/logbook)

I write up the journey on [reefsalter.com](https://reefsalter.com): the medicals, the modules, the weeks that go well and the ones that don't. There's a [live logbook](https://reefsalter.com/logbook) too, generated straight from my flight records.

## Building

- **[reefsalter.com](https://reefsalter.com)**: my personal site, built in Astro with hand-written CSS and a little GSAP. Pages are styled like pilot paperwork, and the logbook updates itself whenever I log a flight.
- **Logbook automation**: a small pipeline that reads my logbook backups, strips out anything private, and rebuilds the site.
- **Aviation admin tools**: performance charts, weight and balance, and checklist workarounds for formats that really didn't need to be locked up.

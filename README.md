### What's going on here

I'm training towards an ATPL(A) at Skyborne, based out of Vero Beach, Florida — currently in the PA-28-161 Warrior, trying not to think too hard about the fact that I'm meant to eventually land a jet.

Alongside that, I'm finishing a University of West London degree, which means my week is roughly: fly in the morning, write about safety management systems in the afternoon. Nobody warns you ground school never really ends.

Most of the code in this profile exists because flight training generates an unreasonable amount of admin, and I'd rather automate it than do it twice.

### What I actually build

- **[reefsalter.com](https://reefsalter.com)** — Astro + Tailwind + Framer Motion site documenting the training journey, badly disguised as a personal brand
- Logbook automation — Apps Script that syncs my `logbook.aero` exports and triggers site rebuilds, so the numbers update themselves
- Aviation admin tools — performance chart digitisation, weight & balance data, checklist workarounds for proprietary formats that really didn't need to be proprietary
